# Aula 01 – Apresentação da Disciplina e Contextualização

## Objetivo da aula

A primeira aula teve como finalidade apresentar a disciplina de Frameworks Front-end, explicar o plano de ensino, a metodologia de avaliação e contextualizar a importância do desenvolvimento Front-end no mercado de trabalho. Também foram introduzidos conceitos básicos sobre JavaScript, frameworks modernos e as atividades que serão desenvolvidas durante o semestre. :contentReference[oaicite:0]{index=0}

---

# O que é Front-end?

O Front-end corresponde à camada de uma aplicação com a qual o usuário interage diretamente. É responsável pela construção das interfaces, organização visual dos elementos, experiência do usuário (UX) e comunicação com os sistemas responsáveis pelo processamento dos dados. :contentReference[oaicite:1]{index=1}

---

# Importância dos Frameworks Front-end

Atualmente, a maior parte das aplicações web utiliza algum framework Front-end para facilitar o desenvolvimento. Esses frameworks permitem criar interfaces mais rápidas, organizadas, reutilizáveis e fáceis de manter, tornando-se um requisito importante para empresas que desenvolvem soluções web. :contentReference[oaicite:2]{index=2}

Durante o semestre serão estudados principalmente:

- React
- Vue.js
- Angular

Além de conceitos relacionados à arquitetura baseada em componentes, gerenciamento de estado, rotas e integração com APIs. :contentReference[oaicite:3]{index=3}

---

# JavaScript (Vanilla JS)

Antes da utilização de frameworks, será utilizada a linguagem JavaScript em sua forma "pura" (Vanilla JS).

O JavaScript é uma linguagem interpretada essencial para o desenvolvimento Front-end e serve como base para praticamente todos os frameworks modernos. Com ele é possível manipular elementos da página, implementar regras de negócio, interagir com APIs e criar interfaces dinâmicas. :contentReference[oaicite:4]{index=4}

---

# Conteúdo da disciplina

Durante o semestre serão abordados temas como:

- Ambiente de desenvolvimento;
- Frameworks CSS e Front-end;
- Componentização;
- Desenvolvimento de interfaces;
- Boas práticas de programação;
- Deploy de aplicações Web. :contentReference[oaicite:5]{index=5}

Ao final da disciplina, o objetivo é que o aluno seja capaz de desenvolver aplicações modernas utilizando Frameworks Front-end, utilizar Git e GitHub e publicar aplicações na Web. :contentReference[oaicite:6]{index=6}

# Metodologia

A disciplina será baseada em:

- Aulas expositivas;
- Discussões em sala;
- Estudos de caso;
- Desenvolvimento de projetos práticos;
- Integração entre teoria e prática. :contentReference[oaicite:7]{index=7}

# Avaliação

A nota será composta por:

- Desenvolvimento do projeto;
- Apresentação do projeto;
- Atividades realizadas durante o semestre;
- Projeto Integrador;
- Autoavaliação. :contentReference[oaicite:8]{index=8}

Além disso, toda a documentação do projeto deverá ser organizada como um mini TCC, contendo planejamento, desenvolvimento, resultados, dificuldades e soluções adotadas. :contentReference[oaicite:9]{index=9}

---

# Atividade da Aula

Como primeira atividade prática, foi proposta a criação de um projeto utilizando HTML, CSS e JavaScript (Vanilla JS). O projeto deverá ser versionado utilizando Git e GitHub e publicado na plataforma Vercel. :contentReference[oaicite:10]{index=10}

Também foi solicitado que cada grupo mantenha um repositório principal da disciplina contendo os resumos das aulas em Markdown e os links para as atividades desenvolvidas ao longo do semestre. :contentReference[oaicite:11]{index=11}

# Principais conceitos aprendidos

# Conclusão

A primeira aula serviu para apresentar toda a estrutura da disciplina e mostrar a importância do desenvolvimento Front-end no mercado atual.
