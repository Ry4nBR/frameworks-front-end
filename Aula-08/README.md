# Aula 08 - Projeto React

## Sobre a aula

Oitava aula da disciplina de Frameworks Front-end, dedicada à consolidação prática e aprofundamento no ecossistema React. A aula inicia com uma revisão sólida dos fundamentos de JavaScript essenciais para o desenvolvimento moderno e avança pelos conceitos fundamentais que estruturam as aplicações em React.

Foi realizada uma revisão abrangente de JavaScript: declaração de variáveis com escopos de função e bloco (`var`, `let`, `const`), tipagem de dados, operadores, estruturas condicionais e de repetição, funções, objetos, métodos de array e manipulação e seleção de elementos do DOM.

Em seguida, o foco voltou-se para os pilares do React: a sintaxe JSX e a interpolação de expressões, componentização funcional com boas práticas e composição hierárquica, transmissão de dados unidirecional através de `props`, o funcionamento e arquitetura do Virtual DOM e do processo de Reconciliação, renderização dinâmica de coleções com `map()` e uso correto de chaves (`key`), e estratégias de renderização condicional utilizando `if/else`, operador ternário (`? :`) e operador lógico AND (`&&`).

## Conteúdos

- Revisão Abrangente de JavaScript Moderno:
  - Inclusão de scripts (in-line, externos e manipuladores de eventos)
  - Variáveis e Escopo: `var` (escopo de função) vs `let` e `const` (escopo de bloco)
  - Tipos de Dados Primitivos e Estruturados (`String`, `Number`, `Boolean`, `Undefined`, `Null`, `Object`, `Array`, `Symbol`, `BigInt`)
  - Operadores Aritméticos, Comparação e Lógicos
  - Estruturas de Controle de Fluxo: Condicionais (`if/else`) e Repetições (`for`, `while`)
  - Funções Tradicionais e Arrow Functions
  - Objetos e Arrays
  - Seleção e Manipulação do DOM (`getElementById`, `querySelector`, manipuladores de eventos)
- Fundamentos e Arquitetura do React:
  - O que é JSX (JavaScript XML) e Interpolação de Expressões com `{}`
  - Diferenças entre JSX e HTML clássico (`className`, `htmlFor`, fechamento de tags)
  - Componentização Funcional: Criação, Convenções e Composição de Páginas
  - Passagem de Dados via `props` e Fluxo de Dados Unidirecional (Pai para Filho)
  - Virtual DOM: Estrutura em Memória, Comparação (*Diffing*) e Reconciliação
  - Renderização de Listas e Coleções Dinâmicas com `map()` e Atributo `key`
  - Renderização Condicional: `if/else`, Operador Ternário (`? :`) e Operador Lógico (`&&`)
- Atividade Prática

## Atividade

A atividade prática consiste no desenvolvimento e publicação de uma aplicação completa em React contemplando todos os tópicos ministrados:

1. Criação de uma aplicação estruturada em componentes reutilizáveis utilizando JSX;
2. Comunicação entre componentes utilizando transmissão explícita de `props`;
3. Demonstração prática do fluxo do Virtual DOM;
4. Transformação e renderização de listas dinâmicas de itens a partir de arrays com `map()` e atribuição única de `key`;
5. Implementação de múltiplos cenários de renderização condicional (estados de carregamento, alternância de mensagens, controle de autenticação ou exibição de resultados);
6. Criação de repositório público no GitHub com documentação no `README.md` detalhando visão geral, funcionalidades implementadas e os conceitos de React aplicados.
