# Aula 07 - Frameworks CSS

## Sobre a aula

Sétima aula da disciplina de Frameworks Front-end, destinada ao estudo aprofundado de estilos em aplicações Web, abordando desde os fundamentos de CSS, Box Model, Flexbox e Design Responsivo até a utilização de Frameworks CSS modernos com ênfase no Tailwind CSS e na abordagem Utility-First.

Foram revisados os conceitos e sintaxe do CSS, as formas de aplicação (in-line, interno e externo), seletores de classe e ID, propriedades fundamentais de estilização e o modelo de caixas (Box Model: Content, Padding, Border e Margin). A aula explorou em detalhes o módulo Flexbox para alinhamento e distribuição unidimensional de componentes em layouts responsivos.

Em seguida, foram introduzidos os Frameworks CSS, contextualizando os desafios do desenvolvimento CSS tradicional (manual) e as vantagens da padronização de interfaces. Foi apresentado o Tailwind CSS, seu paradigma Utility-First, instalação via Play CDN e Tailwind CLI, integração com frameworks modernos, extensão Tailwind IntelliSense e construção de interfaces customizadas e responsivas combinando classes utilitárias.

## Atividade

A aula contou com duas atividades práticas:

### Atividade 01

Criação de um projeto Web estruturado com arquivos `index.html` e `style.css` (CSS Externo via tag `<link>`):
1. Inclusão de 20 elementos com manipulação de todas as propriedades do Box Model (`content`, `padding`, `border`, `margin`);
2. Aplicação de 20 propriedades de Flexbox para organizar e alinhar os elementos de forma responsiva.

### Atividade 02

Desenvolvimento de uma interface utilizando o framework Tailwind CSS:
1. Utilização de pelo menos 30 classes utilitárias diferentes do Tailwind CSS, contemplando cores, tipografia, espaçamentos, dimensões, bordas, posicionamento, flexbox, grid e responsividade;
2. Organização e entrega em repositório no GitHub com documentação em Markdown contendo capturas de tela do código, da aplicação em execução, lista explicativa das classes utilizadas e o link do projeto.
