# Aula 04 - Consumindo APIs no Front-end

## Sobre a aula

Quarta aula da disciplina de Frameworks Front-end, destinada ao estudo da integração e consumo de APIs em aplicações Web, conceitos de arquitetura cliente-servidor e desenvolvimento de serviços backend básicos.

Foram apresentados os conceitos de API (Application Programming Interface), estilo arquitetural REST, protocolo HTTP, métodos de requisição, endpoints, formato de dados JSON, catálogo de APIs públicas, servidores backend e web services.

Também foram abordados a criação de uma API REST utilizando Express.js e Node.js, tratamento de CORS (Cross-Origin Resource Sharing) e deploy de web services na plataforma Render.

## Conteúdos

- API (Application Programming Interface)
- Estilo Arquitetural REST
- Protocolo HTTP
- Modelo Cliente-Servidor e Stateless
- Métodos HTTP (GET, POST, PUT, PATCH, DELETE)

- Catálogos e Repositórios de APIs Públicas
- Formato JSON (JavaScript Object Notation)
- Servidor Backend e Web Service
- Framework Express.js
- Comparação: Node.js Puro vs Express.js
- Casos de Uso do Express.js
- Configuração de CORS
- Deploy e Hospedagem de Web Services no Render
- Atividades Práticas

## Atividade

A aula contou com duas atividades práticas:

### Atividade 01

Pesquisa no GitHub de 10 projetos que utilizem consumo de APIs em suas aplicações. Os projetos devem ser clonados e analisados, identificando o framework utilizado e as APIs consumidas, organizando os dados em um arquivo Markdown com tabela detalhada.

### Atividade 02

Desenvolvimento de uma API utilizando Express, definindo uma rota para consulta de data e hora atual. Realização do deploy do serviço no Render, garantindo seu acesso online. Em seguida, desenvolvimento de uma aplicação Front-end que consuma essa API e apresente a data e a hora na interface.

A API e o Front-end devem ser organizados em repositórios separados no GitHub, acompanhados de documentação com capturas de tela do código, da aplicação em funcionamento e dos painéis de gerenciamento do Render e da Vercel.
