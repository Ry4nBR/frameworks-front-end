# Frameworks Front-end

Repositório acadêmico destinado ao registro e organização dos conteúdos, materiais e anotações desenvolvidos durante a disciplina de **Frameworks Front-end**.

Este repositório foi criado como um espaço pessoal de estudo, reunindo os materiais apresentados em aula, minhas anotações, resumos e outros recursos utilizados ao longo da disciplina.

---

## Objetivo

Organizar os conteúdos da disciplina de forma simples e acessível, facilitando:

- Acompanhar o conteúdo de cada aula;
- Revisar os assuntos estudados;
- Consultar minhas anotações;
- Relembrar conceitos importantes;
- Centralizar os materiais disponibilizados pelo professor;
- Registrar minha evolução ao longo da disciplina.

O repositório será atualizado conforme novas aulas forem realizadas.

---

## Organização

Os conteúdos estão separados por aula.

Cada pasta possui, quando aplicável:

| Arquivo/Pasta | Descrição |
|---|---|
| `README.md` | Informações e conteúdo principal da aula |
| `anotacoes.md` | Anotações realizadas durante a aula |
| `resumo.md` | Resumo dos principais conceitos estudados |
| `aula.pdf` | Material ou apresentação disponibilizado para a aula |
| `imagens/` | Imagens, capturas de tela, diagramas e outros materiais relacionados |

### Estrutura

```bash
aula-01/
├── README.md
├── anotacoes.md
├── resumo.md
├── aula.pdf
└── imagens/
```

A estrutura poderá ser ajustada ao longo da disciplina conforme a necessidade de organização dos materiais.

# Materiais de Estudo

Cada aula pode conter diferentes tipos de materiais.

## Anotações

Arquivo `anotacoes.md` destinado às anotações realizadas durante a aula.

Pode conter:

- Explicações do professor;
- Exemplos apresentados;
- Comandos;
- Códigos;
- Observações importantes;
- Dúvidas;
- Informações complementares.

## Resumo

Arquivo `resumo.md` destinado à revisão do conteúdo.

O objetivo é transformar as anotações da aula em um material mais direto para estudar posteriormente.

## Material da aula

O arquivo `aula.pdf` contém o material disponibilizado para a respectiva aula, quando disponível.

## Imagens

A pasta `imagens/` pode ser utilizada para armazenar:

- Capturas de tela;
- Diagramas;
- Imagens utilizadas durante a aula;
- Exemplos visuais;
- Outras referências relacionadas ao conteúdo.
