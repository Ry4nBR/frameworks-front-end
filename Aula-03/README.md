# Aula 03 - Projetos com Frameworks Front-end

## Sobre a aula

Terceira aula da disciplina de Frameworks Front-end, destinada à introdução aos Frameworks Front-end e à apresentação das principais tecnologias utilizadas no desenvolvimento de aplicações Web.

Foram apresentados os conceitos de Framework e Biblioteca, as características dos Frameworks Front-end e as tecnologias React, Angular, Vue e Next.js.

Também foram abordados conceitos relacionados à criação e estrutura de projetos, importação de projetos existentes e versionamento com Git.

## Atividade

A atividade prática da aula consiste no desenvolvimento, em grupo, de quatro projetos Web sobre o mesmo tema, utilizando React, Vue, Angular e Next.js.

Cada projeto deverá apresentar uma página funcional, responsiva e organizada, utilizando componentes e os recursos básicos da tecnologia escolhida.

Durante o desenvolvimento, os projetos deverão ser versionados com Git e publicados no GitHub, mantendo um histórico de commits que registre a evolução das aplicações.

### Projetos

- Projeto 01: React
- Projeto 02: Vue
- Projeto 03: Angular
- Projeto 04: Next.js
- Projeto 05: Cópia de um projeto a partir de um repositório

Ao final, deverá ser realizada uma breve comparação entre as quatro tecnologias, destacando as principais diferenças encontradas durante o desenvolvimento.
