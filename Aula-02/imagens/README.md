# Aula 02 - Configuração do Ambiente de Desenvolvimento

## Sobre a aula

Segunda aula da disciplina de Frameworks Front-end, destinada à configuração do ambiente de desenvolvimento e à introdução de ferramentas utilizadas no desenvolvimento de aplicações Front-end.

Foram apresentados conceitos de versionamento, Versionamento Semântico (SemVer), Git, tags, branches, boas práticas de versionamento, IDE e Visual Studio Code, Node.js, NPM, criação de projetos React e deploy utilizando a Vercel.

## Conteúdos

- Introdução ao Versionamento
- Versionamento x Backup
- Benefícios do Versionamento
- Versionamento Semântico (SemVer)
- Exemplos de alterações no código
- Importância do Versionamento
- IDE e Visual Studio Code
- Introdução ao Git
- Instalação e configuração do Git
- Tags no Git
- Boas Práticas no Git
- Node.js
- Node Package Manager (NPM)
- Criação de um Projeto React
- Estrutura de um Projeto React
- Deploy
- Vercel para Deploy e Hospedagem

## Atividade

A atividade prática da aula consiste no desenvolvimento de uma aplicação React utilizando o Visual Studio Code como ambiente de desenvolvimento.

O projeto deve ser versionado utilizando Git, publicado em um repositório no GitHub e posteriormente disponibilizado online por meio de um deploy na Vercel.

Também foi proposta uma atividade em grupos para a escolha de um Framework Front-end e elaboração de um relatório técnico em PDF, com no mínimo 5 páginas.

O relatório deve apresentar:
